# The architect's notebook

Het probleem wat ik heb, is dat m'n kennis over de architectuur versnippert raakt over verschillende tools,
ik gebruik graag draw.io voor m'n sketches, en markdown in een gitrepo voor m'n documentatie. Maar er staan ook rationales 
in Basecamp (de project management tool die ik voor mijn pet projecten gebruik).

En op m'n day-job is het nog erger, kennis verspreid over teams kanalen, wiki's, project management tools,
emails, chats, markdown/tekst bestandjes in een mapje voor "notes" (de vorm factor )
